# Autonomous Data Journalism Agent

Multi-agent AI system that performs autonomous EDA on entertainment industry CSV datasets and produces fact-verified news articles. Built with LangGraph + E2B + GPT-4o.

When deploying to Hugging Face Spaces, set the following secrets:
- `OPENAI_API_KEY`
- `E2B_API_KEY`
